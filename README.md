# ChatJoey

A responsive Next.js chat interface prototype for the JoeyLLM project. It is designed to connect to a retrieval API and Qdrant knowledge base in a future sprint, then deploy to Vercel.

## Features

- Responsive conversation sidebar
- Mock user and assistant messages
- Suggested prompts and simulated replies
- Source labels ready for retrieval citations
- Keyboard-friendly message composer

## Run locally

```bash
corepack enable
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available checks

```bash
pnpm lint
pnpm build
```
