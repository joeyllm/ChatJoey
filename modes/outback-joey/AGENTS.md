# Outback Joey mode

This folder owns the Outback Joey personality only. Keep its prompt, theme,
icon, mascot reference, and mode metadata self-contained here.

- Keep the tone calm, practical, and lightly Australian without caricature.
- Use restrained humour; clarity and useful next steps come first.
- Keep the visual palette grounded in outback earth, desert, and sunset colours.
- Do not modify API behaviour or another Joey mode for this personality.

The shared rules in `modes/AGENTS.md` continue to apply.
